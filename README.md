# 🚗 ESP32-CAM Robot Car

Aplicativo desenvolvido em React Native para controlar um carrinho robótico equipado com ESP32-CAM por meio de Bluetooth Low Energy (BLE).

Funcionalidades
Conexão com o carrinho via Bluetooth (BLE).
Envio de comandos para controle de movimento.
Comunicação em tempo real com o ESP32-CAM.
Tecnologias
React Native
JavaScript
React Native BLE PLX
ESP32-CAM
Bluetooth Low Energy (BLE)
